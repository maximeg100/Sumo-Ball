# Sumo-Ball
Jeu Unity 3D de sumo. Vous contrôlez une balle, tandis que les ennemis se dirigent dans votre direction. Il ne faut pas tomber sinon vous perdez. A chaque vague d'ennemi, le nombre d'ennemis augmente. Des boosts permettent de pousser avec plus d'intensité les ennemis. 

Ce jeu a été fait en suivant le site officiel : https://learn.unity.com/pathway/junior-programmer/unit/gameplay-mechanics/tutorial/lesson-4-1-watch-where-you-re-going-2?version=6.0

Vous pouvez tester le jeu en suivant ce lien : https://play.unity.com/en/games/e6365a64-de10-4be5-a266-4cba1105cc1a/exportwebsumo
